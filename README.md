# 📊 Sales Analysis Dashboard (MS Excel)

This repository contains the final hands-on project for the **MS Excel Module** at **ID Tech Data Analytics Bootcamp**.

---

## 📌 Project Overview
The main objective of this project is to transform raw sales transactional data into meaningful business insights through data cleaning, key performance indicator (KPI) calculations, and interactive visualizations.

### 🔑 Key Features & Highlights:
- **Data Cleaning & Preparation:** Structured raw dataset for analytical readiness.
- **KPI Metrics:** Calculated Total Profit ($322,966.75), Net Revenue ($15,379.37), and Total Quantity Sold (5,510 units).
- **Pivot Tables & Trend Analysis:** 
  - Profit trends by category and month (Jan - Mar 2021).
  - Profit distribution across male and female customer demographics.
  - Sales performance across branches/cities (Mandalay, Naypyitaw, Yangon).
- **Interactive Sales Dashboard:** Dynamic slicers filtering data by Gender, City, and Customer Rating.
